# absurd-memes

Генератор абсурдных мемов: случайное фото + случайная фраза, никак не связанные между собой.

- Фото: [Picsum](https://picsum.photos)
- Фразы: фильмы, мультфильмы и сериалы из [Викицитатника](https://ru.wikiquote.org)
- Одно слово: русские существительные из [Викисловаря](https://ru.wiktionary.org)

Чистый JS без сборки, хостинг на GitHub Pages.

## Ссылки с параметрами

Любой мем можно описать ссылкой. Не заданное генерируется случайно.

| Параметр | Значения |
|---|---|
| `mode` | `word`, `phrase`, `dialog` |
| `text` | свой текст, реплики через `\|` |
| `img`, `size` | id фото Picsum и размер, например `1084` и `1200x800` |
| `pos` | `auto`, `top`, `bottom`, `both`, `center` |
| `mat` | `1` разрешает мат |
| `fs` | масштаб текста, от `0.5` до `2` |
| `view` | `clean` показывает только картинку |

Пример: `?text=Колбасы&pos=bottom`

## Структура

```
src/sources/   источники: images, phrases (+ quoteParser), words, fallback
src/layout.js  поиск спокойного места для текста
src/render.js  рисование на canvas
src/editor.js  перетаскивание надписей
src/share.js   буфер, скачивание, поделиться
src/params.js  параметры в адресе
src/app.js     связывает всё
```
